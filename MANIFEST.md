# Manifest

This repository includes:

- `README.md`: reviewer-facing replication instructions.
- `requirements.txt`: Python dependency list.
- `projects/`: per-project input data used by the experiment.
- `scripts-anon/`: anonymization code.
- `scripts-results/`: evaluation, statistics, plotting, and orchestration code.
- `LACE/`: vendored LACE code used for comparison/reference.
- `artifacts/precomputed_outputs.zip`: precomputed outputs containing `anon_results/`, `lace-results/`, and `results/`.
